Phase 5 locked decisions implemented here:
- D-01: closed typed failure-classification enum with `none`, `lifecycle`, `trajectory`, `map_fusion`, `agent_query`.
- D-02: failure classes are gate-derived; each `RegressionGate` carries the failure class it represents.
- D-03: priority order is lifecycle before trajectory before map/fusion before agent-query; all failed results remain inspectable.
- D-04: lifecycle failure semantics must be based on tracking states and processing completeness, especially `TrackingState.LOST`, `TrackingState.NOT_INITIALIZED`, or incomplete processing. This plan provides the gate taxonomy and readiness plumbing; Plan 05-02 metrics/diagnostics provide the lifecycle inputs.
- D-13/D-16: real 3DGS backend integration remains blocked until a non-empty deterministic benchmark suite produces passing regression gates covering lifecycle, trajectory, map_fusion, and agent_query classes, exposed by a typed helper in `mosaic.evaluation.regression`.
