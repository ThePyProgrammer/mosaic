<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Optional backend descriptor to contract helper | Helper decides whether to skip or instantiate a backend based on availability diagnostics. |
| Backend process output to helper assertions | Backend implementations return diagnostics and update objects consumed by tests as contract evidence. |
| Shared helper to future real backends | Helper must validate generic lifecycle invariants without overfitting deterministic fake backend internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege / Denial of Service | `skip_unavailable_backend` and helper setup | mitigate | Call descriptor availability before factory creation; tests use missing dependency descriptor and assert skip happens with diagnostic text before backend creation. |
| T-03-02 | Spoofing / Tampering | Descriptor identity consumed by helper tests | mitigate | Depend on Plan 03-01 duplicate-name rejection; helper tests use explicit descriptors and factories rather than global mutable overrides. |
| T-03-03 | Tampering | Availability and diagnostic mappings | mitigate | Consume immutable `AvailabilityResult` and assert diagnostic values are JSON-ready scalars; no helper mutates descriptor metadata. |
| T-03-04 | Repudiation / Information Integrity | Contract helper diagnostics and skip reasons | mitigate | Skip reason includes missing requirement/install hint; update diagnostics checked for scalar machine-readable values. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install tasks exist in this plan; pytest is already declared in project dev dependencies. |
</threat_model>
