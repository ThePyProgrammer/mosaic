<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| synthetic fixture/caller update→aggregate memory | Caller-provided cells, entities, relations, claims, notes, and commitments enter the aggregate snapshot. |
| aggregate memory→agent tool consumer | Query methods expose bounded result rows to future agent runtimes. |
| belief state→query outputs | Conflicts/staleness must remain visible in result rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Denial of Service | `find_perception_matches`, `query_navigation_frontiers`, `list_coordination_commitments`, `inspect_belief`, `summarize_context` | mitigate | Require positive `max_results`/`max_notes`, slice returned rows, and expose `total_matches`/`truncated`. |
| T-07-03-02 | Information Disclosure | aggregate memory query methods | mitigate | Return bounded row objects, IDs, evidence refs, status, and confidence only; do not expose raw full memory dumps through tool methods. |
| T-07-03-03 | Tampering | aggregate update helpers | mitigate | Return new `RepresentationMemory` snapshots and preserve original snapshots; tests assert immutable update behavior. |
| T-07-03-04 | Repudiation | conflicted/stale claims in query results | mitigate | Include claim IDs, statuses, conflict IDs, and evidence references in belief/perception/navigation rows where applicable. |
| T-07-03-SC | Tampering | package supply chain | mitigate | Add no dependencies; no package-manager installs. |
</threat_model>
