<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller→representation dataclasses | Untrusted caller-supplied IDs, confidence values, metadata, evidence URIs, timestamps, and memory entries enter immutable contract objects. |
| representation contracts→agent consumers | Public objects may be consumed by agent runtimes; contracts must not expose unbounded raw state or claim real perception. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Tampering | `SourceMetadata`, `EvidenceReference`, memory-family records | mitigate | Freeze dataclasses with `frozen=True, slots=True`, tuple-convert sequence fields, and freeze mappings with `MappingProxyType(dict(...))`. |
| T-07-01-02 | Information Disclosure | `EvidenceReference.uri` | mitigate | Treat evidence URIs as opaque strings only; implement no dereference/load methods per D-09. |
| T-07-01-03 | Spoofing | `SourceMetadata.source_id` | accept | Source IDs are representation metadata, not authentication; validate nonblank values but do not claim identity verification. |
| T-07-01-04 | Denial of Service | constructor inputs | mitigate | Validate nonblank IDs, confidence bounds, positive resolution, and valid time windows before objects become public state. |
| T-07-01-SC | Tampering | package supply chain | mitigate | Add no new runtime dependencies; Phase 7 uses stdlib, existing `pytest`, and local Mosaic modules only. |
</threat_model>
