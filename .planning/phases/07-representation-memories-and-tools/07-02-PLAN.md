<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| robot/source report→claim memory | Caller-provided robot reports become claims that may conflict or expire. |
| evidence URI→belief consumer | Evidence identifiers and URIs are exposed to consumers without loading payloads. |
| belief memory→agent query layer | Later tool methods will rely on claim status; hidden winner selection would mislead agents. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | `Claim.confidence`, `Claim.status`, `Claim.conflicts_with` | mitigate | Validate confidence range, freeze tuples, reject self-conflicts, and require explicit status values. |
| T-07-02-02 | Repudiation | contradictory robot claims | mitigate | Keep both contradictory claims present with reciprocal `conflicts_with` links and `ClaimStatus.CONFLICTED`; tests assert no hidden winner. |
| T-07-02-03 | Information Disclosure | `EvidenceReference.uri` | mitigate | Keep evidence references typed and opaque; no dereference/load method exists. |
| T-07-02-04 | Denial of Service | stale transition over claims | accept | Phase 7 in-memory fixtures are small; bounded query methods arrive in Plan 07-03. Preserve simple deterministic tuple scan. |
| T-07-02-SC | Tampering | package supply chain | mitigate | Add no dependencies; use only stdlib and local Mosaic types. |
</threat_model>
