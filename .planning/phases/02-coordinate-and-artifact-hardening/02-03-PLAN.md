<interfaces>
New artifact envelope contract:
- Every artifact helper returns a JSON-ready dict with exactly these top-level keys: "schema", "schema_version", "payload".
- schema_version must be integer 1.
- Unknown schema names and unknown schema_version values must raise ValueError before constructing domain objects.
- Timestamp payload stores {"nanoseconds": int}.
- Pose3 payload stores parent_frame string, child_frame string, translation list [x, y, z], and rotation_wxyz list [w, x, y, z].
- ImageBuffer payload stores width, height, channels, encoding string, data_encoding="base64", and data as a base64 ASCII string.
- GaussianSplat payload stores center list, covariance_upper list in (xx, xy, xz, yy, yz, zz) order, color_rgb list, opacity, and provenance.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external dict/JSON -> artifact loaders | Untrusted serialized data is validated before constructing typed Mosaic value objects. |
| ImageBuffer bytes -> JSON artifact | Raw bytes cross into JSON-only payloads and must use explicit reversible encoding. |
| splat artifacts -> GaussianSplat | Covariance payloads cross into uncertainty semantics and must preserve tuple order plus existing validation. |
